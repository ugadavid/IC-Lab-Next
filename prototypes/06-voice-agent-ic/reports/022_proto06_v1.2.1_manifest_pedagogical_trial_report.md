## Resume executif

Essai pedagogique realise sur Prototype 06 V1.2.1 avec le manifest local `climate-roundtable-demo`.

Recommandation : pret pour preparer le palier Hub V0.9.8, avec un micro-ajustement pedagogique recommande avant exposition plus large.

## Lecture pedagogique

### Est-ce que l'activite donne envie d'etre testee avec un etudiant ?

Oui, pour un essai court. L'activite est suffisamment concrete : une mini-table ronde, trois personnages, trois langues romanes, un theme commun sur le climat. Le premier tour affiche immediatement un temoignage comprehensible par indices, ce qui correspond bien a l'esprit intercomprehension.

### Est-ce que la consigne est assez claire ?

Partiellement. La consigne specifique du manifest est presente dans l'activite, mais le texte visible au chargement reste generique : `Demarrez la rencontre. Vous pourrez repondre apres les trois prises de parole.`

Micro-ajustement utile : afficher des le chargement la consigne du manifest ou un court sous-titre du type : `Ecoutez trois temoignages romans et reconstruisez les changements climatiques compris.`

### Est-ce que le lien climat, langues romanes et intercomprehension est visible ?

Oui. Les indices transparents, les langues et l'observation initiale rendent le lien assez lisible. Le theme climatique est explicite dans l'objectif et dans les observations.

Micro-ajustement utile : rendre le theme `climat` plus visible dans la zone de scene centrale, pas seulement dans la carte enseignante et les observations.

### Est-ce que le manifest semble etre un bon format de publication ?

Oui. Le manifest se comporte comme un objet de publication pedagogique : il contient personnages, scenario, consigne, tours, observations et garde-fous. Il est assez autonome pour etre servi plus tard par le Hub sans transformer Prototype 06 en client IA.

Point a conserver : `meeting.steps[].generated=false` et `review.reviewStatus=human-reviewed` sont des signaux importants pour distinguer publication pedagogique et brouillon IA.

### Micro-ajustements pedagogiques utiles avant Hub V0.9.8

1. Afficher la consigne manifest des le chargement.
2. Ajouter un badge visible : `Activite publiee - runtime scenarise`.
3. Harmoniser les accents dans le fixture si l'activite doit etre montree telle quelle.
4. Clarifier la difference entre `manifest local indisponible` et `activite de demonstration locale`.
5. Eventuellement afficher `source : manifest local` dans la carte enseignante ou le debug, sans exposer le JSON complet.

## Problemes visuels ou UX eventuels

- Le panneau enseignant rassure bien sur l'absence d'IA reelle, mais il est un peu dense : objectif + runtime + IA reelle sont colles dans une meme ligne.
- Le titre principal reste `Rencontre plurilingue REPLI4C`; c'est coherent, mais l'activite specifique pourrait etre plus visible dans le premier ecran.
- Le fallback invalide est clair, mais le lien `Revenir a la demonstration locale` pourrait etre accentue et reformule plus naturellement dans une passe UX.
- Les textes du fixture sont volontairement ASCII; pour une demonstration humaine, une version accentuee en UTF-8 serait plus agreable.
