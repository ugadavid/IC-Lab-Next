## Ajustements pedagogiques

### Consigne manifest affichee plus tot

Quand un manifest valide est charge, V1.2.2 remplace le texte generique initial par :

```txt
Ecoutez les temoignages et reconstruisez le theme commun a partir d'indices partiels.
```

L'encadre d'aide affiche maintenant la question commune :

```txt
Quels changements avez-vous compris et quels points communs reliez-vous entre les participants ?
```

La scene centrale affiche le `shortTitle` du manifest :

```txt
Constats climatiques
```

### Badge pedagogique visible

La carte enseignante affiche trois badges :

- `Activite publiee`;
- `Runtime scenarise`;
- `IA reelle non active`.

Ces badges rendent visible la nature prudente de l'activite sans exposer le JSON, sans donner de details techniques inutiles et sans alourdir le parcours apprenant.

### Manifest invalide

Le lien de retour est reformule :

```txt
Ouvrir la demonstration locale sans manifest
```

Le message d'erreur technique reste lisible, mais la sortie proposee est plus naturelle que dans V1.2.1.

## Recommandation pour Hub V0.9.8

Prototype 06 V1.2.2 est pret pour preparer le palier Hub V0.9.8.

Perimetre recommande pour V0.9.8 :

- ajouter un endpoint Hub lecture seule pour manifests publies;
- ne servir que des manifests `published` ou `human-reviewed`;
- ne pas brancher les brouillons IA directement;
- conserver le runtime scenarise;
- transmettre `manifestId` dans l'URL de lancement;
- garder `activitySnapshot` cote Hub pour visibilite si Prototype 06 est indisponible.

Le principe doit rester le meme : le Hub publie une activite pedagogique validee, Prototype 06 la joue en mode scenarise, et l'IA admin reste en dehors du parcours apprenant.
