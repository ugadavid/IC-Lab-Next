## Strategie de lecture du statut Hub

La page sandbox cherche une session Hub existante sous la cle navigateur deja utilisee par IC-Hub :

```txt
icHubAuthToken
```

La session est lue uniquement si elle existe dans le navigateur courant. Elle n'est jamais affichee, jamais journalisee et jamais copiee dans le DOM.

Si une session est disponible, la sandbox appelle le pont Hub avec :

```txt
Authorization: Bearer <token masque>
```

Si aucune session n'est exploitable depuis l'origine `127.0.0.1:8788`, la page affiche un message clair et garde la generation desactivee.
