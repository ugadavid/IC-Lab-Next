# Workflow Codex

## Philosophie du projet

⚠️ Projet en phase de démarrage exploratoire
Le système actuel est un prototype. Les entretiens de terrain sont encore en cours et peuvent modifier substantiellement les besoins, la structure ou les priorités du projet. Les décisions techniques doivent rester légères, réversibles et documentées.


Nous privilégions :
- simplicité
- explicabilité
- petites itérations

## Règles importantes

### 1. Ne jamais sur-ingénier

Préférer une solution simple.

### 2. Ne jamais modifier massivement le modèle

Proposer avant.

### 3. Toujours documenter les changements

Expliquer pourquoi.

### 4. Préserver les données existantes

Éviter les migrations destructives.

### 5. Procédures stockées

Préfixe obligatoire :
sp_

### 6. Relations lexicales

Ne jamais inventer massivement des cognats.

Privilégier :
- données prudentes
- cas pédagogiquement utiles

### 7. Le projet démarre

Le modèle n’est pas stabilisé.

Les retours des enseignants et entretiens
doivent pouvoir faire évoluer le système.
